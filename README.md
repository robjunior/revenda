# revenda

Sistema de gestão e automação para lojas de veículos.

**Landing page:** https://robjunior.github.io/revenda/

O documento do projeto está em [IDEA.md](IDEA.md). A página publicada vive na branch `gh-pages`;
o `main` fica livre para o código do sistema.

## Estrutura

- `IDEA.md` — conceito, módulos, etapas, tráfego pago e modelo comercial
- branch `gh-pages` — landing page (`index.html`) e imagens (`img/`)
